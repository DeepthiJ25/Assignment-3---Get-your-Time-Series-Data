# Netflix Streaming Revenue and Membership by Region Data Set

## Data Dictionery

| Variable Name | Type | Description |
|---------------|------|-------------|
| `quarter_ending` | Date (DD-MM-YYYY) | Last date of the fiscal year |
| `region` | String | Geographic region of Netflix subscribers and revenue (e.g., `UCAN`, `EMEA`, `LATAM`, `APAC` ) |
| `currency` | Float | The revenue is in million U.S. dollars |
| `revenues_USD_thousands` | Numeric | Quarterly streaming revenue for the region, reported in thousands of US dollars |
| `paid_net_additions` | Numeric | Net change in paid memberships compared to previous quarter.negative = subscriber loss |
| `paid_memberships_end` | Numeric | Number of paid memberships at the end of the quarter |
| `average_paying_memberships` | Numeric | Quarterly average number of paying memberships |
| `average_revenue_per_membership` | Numeric | Average revenue per paying membership during the quarter in US dollars |
| `YoY_change_percent` | Percentage | Percentage change in revenue compared to the same quarter in the prior year |

## Data Collection Method

To analyze *Netflix’s quarterly revenue and membership streaming* trends and forecast future revenue. 
The quarterly for the years 2017 - 2024 was collected. 
The data was collected from Netflix's official website, which includes their financial releases for quarterly and annual earnings.
